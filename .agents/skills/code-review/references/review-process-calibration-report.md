# Review Process Calibration Report

The updated workflow was applied to five verified failure shapes. The calibration used the changed production paths and downstream consumers below, then checked the independently derived sequence against the named regression tests. Test titles alone were not treated as proof; outcomes were checked against persisted ownership, current session identity, and selected mutation targets.

| Scenario | Requirement used and production path / consumers inspected | Adversarial sequence and false-positive control | Executed evidence |
| --- | --- | --- | --- |
| Media subtree deletion | Bulk set ledger; `useMediaLibraryController.tsx` -> persisted media rows, upload cleanup, Activity retry, finalization. | Start deletion, add a member during cleanup, unmount, then retry. A member still in the persisted subtree must stay recoverable; a changed church session retires the operation. | `Media.test.tsx`: “keeps newly added subtree media recoverable and retries it before finalizing” and related deletion recovery cases; included in the passing 8-suite client run (235 tests). |
