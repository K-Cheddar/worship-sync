# WorshipSync Pattern Catalog

Patterns preserve a reusable architectural approach without turning every related decision into a global rule. Each pattern documents:

- the problem it solves;
- when to use and not use it;
- canonical WorshipSync examples;
- lifecycle and edge cases; and
- verification expectations.

Use a pattern when its behavioral concept matches the task. Do not copy it only because the syntax looks similar.
